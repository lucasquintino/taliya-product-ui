# Spec Kit constitution

## Purpose

Maintain the project constitution and its precedence over feature-level plans.

## Rules

- Keep principles testable, versioned, and enforceable.
- Prefer repository-local evidence over prose claims.
- Resolve conflicts by explicit precedence: constitution, root instructions, scoped instructions, active spec, plan, tasks.
- Every exception requires an owner, expiry, compensating evidence, and approval.

## Output

Publish the version/revision and a change log. Never weaken a higher-precedence rule implicitly.
