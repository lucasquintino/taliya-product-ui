# Spec Kit tasks

## Purpose

Derive executable tasks from an approved specification and plan.

## Procedure

1. Preserve traceability from every requirement and success criterion to at least one task and gate.
2. Include test-first tasks before behavior/enforcement changes.
3. Declare dependencies, parallel safety, files, evidence, and exit criteria.
4. Keep unchecked tasks unchecked until their evidence is fresh and reproducible.

## Output

Produce contiguous stable task IDs and a dependency order that can be executed from a clean clone.
